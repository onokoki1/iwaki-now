# いわきNOW — Prototype v1.0

福島県いわき市のニュースを短く整理して届ける地域情報サイトの静的プロトタイプです。

## すぐ見る
`index.html` をブラウザで開いてください。より本番に近い確認はローカルサーバーで行えます。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 入っている機能
- スマホ / PC レスポンシブ対応
- 今日の5ニュース
- 新着ニュース一覧
- キーワード検索
- カテゴリー絞り込み
- 地域絞り込み
- カード / リスト表示切替
- 記事詳細モーダル
- 元情報へのリンク
- 編集方針 / Aboutページ

## ニュースの追加・更新
`app.js` 冒頭の `news` 配列に記事を追加します。

主な項目：
- `title` 見出し
- `summary` 独自要約
- `category` カテゴリー
- `area` 地域
- `publishedAt` 公開日時
- `source` 出典名
- `sourceUrl` 元情報URL
- `top` 今日の5ニュースに入れるか

## 公開方法
静的サイトなので GitHub Pages / Netlify / Cloudflare Pages / Vercel 等へ、そのまま配置できます。

## 本番化するときの次の実装候補
1. WordPressまたはCMS連携
2. RSS / API /公式サイト巡回による情報収集
3. AI要約案 → 人による承認 → 公開の編集フロー
4. 管理画面
5. OGP画像生成
6. SNS自動投稿
7. Google Analytics / Search Console
8. 独自ドメイン `iwakinow.jp` 等

## 注意
このプロトタイプ内のニュースは2026年8月8日時点の公開情報をもとにしたデモです。公開運用時は情報の最新性、著作権、各媒体の利用条件を必ず確認してください。


## 地域区分
地域フィルターは1966年のいわき市発足時の旧14市町村を基準にしています。表示名は現在の地域名を優先し、小名浜には「旧磐城市」を併記しています。久之浜と大久は別地域として扱います。

## v3 追加機能

### 速報・重要ニュース
`update_news.py` がカテゴリー、緊急語、新しさ、公式情報かどうか、複数媒体での掲載数をもとに重要度を自動計算します。緊急性の高い新着情報はトップに「速報・重要」として表示されます。

### 同一ニュースの統合
近い時間帯に出た類似見出しを自動でまとめます。同じ出来事を複数媒体が掲載している場合は「3媒体が掲載」のように表示し、各媒体へのリンクは記事詳細ページから確認できます。

### 独立記事ページ
更新のたびに `news/<記事ID>.html` を自動生成します。記事ページには概要、地域、カテゴリー、掲載日時、主な出典、同じニュースを掲載した他媒体へのリンクを表示します。

### 更新時に変更されるファイル
- `data/news.json`
- `news/*.html`

GitHub Actions の `Update news` はニュース収集、JSON更新、記事ページ生成、GitHubへの保存、GitHub Pagesへの再公開までを一度に実行します。

## v4 追加機能

### 「開店・閉店」専用欄
トップページに「開店・閉店」欄を追加しました。`update_news.py` は通常のニュース収集に加えて、開店・閉店・オープン・新店舗・移転・リニューアル等のキーワードを含む情報を専用の Google News 検索RSSでも収集します。

収集したニュースには `isOpeningClosing` フラグを付与し、専用欄に最大5件を自動表示します。「一覧で見る」を押すと、新着ニュース欄が開店・閉店情報だけに絞り込まれます。

### 「今週末のイベント」専用欄
日本時間を基準に、その週の土曜日・日曜日を自動計算します。イベント系ニュースのタイトル・概要に含まれる `8月16日`、`8/16`、`8月15日〜16日` などの日付表記を抽出し、今週末に当たるものへ `isWeekendEvent` フラグを付与します。

土曜日・日曜日に更新した場合は「現在の週末」、月曜日〜金曜日に更新した場合は「次の土日」を対象にします。`data/news.json` には対象週末の開始日・終了日・表示ラベルも保存されます。

### v4 の自動更新フロー
1. 公式RSS・地域メディア・Google News検索RSSを収集
2. 開店・閉店／週末イベントの専用検索も実行
3. 重複ニュースを統合
4. 重要度・速報・開店閉店・週末イベントを自動判定
5. `data/news.json` を更新
6. `news/*.html` の記事ページを再生成
7. GitHub に自動コミット
8. GitHub Pages にそのまま再公開

GitHub の `Actions → Update news → Run workflow` で手動更新もできます。定期実行は `.github/workflows/update-news.yml` のスケジュールに従います。
